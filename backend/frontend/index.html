How the Mac App Works ▼

Architecture

Vero uses a two-app model: a visible settings app and a hidden login helper for telemetry.

What the Agent Does

  • Sends heartbeats every 60s
  • Captures active app & window
  • Reads Chrome history (30m)
  • Syncs calendar events

Battery Impact

Minimal. The helper runs brief cycles and sleeps between checks.

Permissions Needed

  • Accessibility — window titles
  • Calendar — event writing
  • Notifications — alerts
