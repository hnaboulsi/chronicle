💻 How the Mac App Works

Architecture

Life Manager uses a two-app model: a visible Settings app for configuration and a hidden background agent that launches at login. The agent has no dock icon or window — it runs silently in the background.

What the Agent Does

  • Sends a heartbeat every 60 seconds to keep the "Online" status.
  • Captures the active app and window title each polling interval (default 60s).
  • Reads Chrome browsing history every 30 minutes for richer activity context.
  • Pulls calendar jobs from the backend and writes them to Apple Calendar via EventKit.
  • Delivers check-in and focus nudge notifications.

Battery Impact

Minimal. The agent sleeps most of the time. Chrome history reads are throttled to every 30 minutes. CPU usage is negligible in Activity Monitor.

Permissions Needed

  • Accessibility — reading window titles for activity tracking.
  • Calendar — writing study/work sessions to Apple Calendar.
  • Notifications — delivering check-ins and focus nudges.
